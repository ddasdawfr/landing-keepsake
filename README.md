# Keepsake — Responsive Landing Page

Адаптивний односторінковий лендінг для дизайн-агенції Keepsake, виконаний у межах Лабораторної роботи №7.

**Live Demo:** [https://ddasdawfr.github.io/landing-keepsake/](https://<ваш-логін-github>.github.io/landing-keepsake/)

\---

## Використані технології

* **HTML5**: Семантична верстка (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **CSS3**:

  * **Flexbox** для гнучкого позиціонування елементів та сітки карточок.
  * **CSS Variables (`:root`)** для централізованого управління кольоровою палітрою, шрифтами та відступами.
  * **Media Queries (`@media`)** для реалізації адаптивності за підходом Mobile-First.
* **Google Fonts / Local WOFF2**: Підключення шрифтів *Oswald*, *Open Sans* та *Dancing Script*.

\---

## Основні технічні рішення

1. **Mobile-First підхід**:

   * Базові стилі розроблені під мобільні пристрої (від 320px до 375px).
   * Для контрольних точок **Tablet (768px)** та **Desktop (1280px)** використані `@media (min-width: ...)` запити.
2. **Інтерактивність без JavaScript (Pure CSS)**:

   * **Мобільне меню:** Реалізовано за допомогою прихованого чекбокса (`<input type="checkbox">`) та CSS-селектора `:checked \~ .mobile-drawer`.
   * **Фільтрація портфоліо:** Побудована на радіо-кнопках (`<input type="radio">`) та селекторі `:checked \~ .works-grid .work-card:not(...)`, що дозволяє фільтрувати роботи без використання JS.
3. **Адаптивна сітка портфоліо (Our Works)**:

   * **Mobile (375px):** 1 колонка, відображаються перші 5 карточок (`aspect-ratio: 1 / 0.72`).
   * **Tablet (768px):** 2 колонки, відображаються 8 карточок (`aspect-ratio: 1 / 0.79`, `gap: 12px`).
   * **Desktop (1280px):** 3 колонки, відображаються всі 9 карточок (`gap: 14px`).
4. **Доступність та Продуктивність (a11y \& Performance)**:

   * Усі інтерактивні елементи підтримують фокус із клавіатури (`:focus-visible`).
   * Іконочні кнопки містять `aria-label` для екранних дикторів.
   * Шрифти підключені з властивістю `font-display: swap` для прискорення завантаження сторінки.
